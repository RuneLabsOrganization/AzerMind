COMO COMEÇAR

Da instalação à primeira conversa

◆
01

Prepare seu aventureiro

Tenha o WoW Forever, Node.js 22.2+ e ao menos um agente de IA instalado e autenticado no computador.

❯
02

Instale o AzerMind

Baixe o projeto e execute o instalador de configuração para copiar os módulos do addon para o jogo.

❯
03

Converse dentro do WoW

Inicie o bridge, entre no jogo e digite /azermind para abrir seu assistente.

Instalação rápida — Windows / PowerShell
git clone https://github.com/mateusmaaia/AzerMind-wow.git
cd AzerMind-wow
npm install
node setup.js
npm start

O instalador detecta o cliente automaticamente na maioria dos casos. O jogo deve estar em modo janela ou sem bordas para a captura de tela. Ler guia completo de instalação ↗

O GRIMÓRIO DE RESPOSTAS

Perguntas frequentes

O essencial antes de começar sua jornada com o AzerMind.

Precisa de ajuda? Abrir um issue ↗
O AzerMind é gratuito?+

Sim. O projeto é open source sob licença MIT. O acesso a agentes, modelos ou serviços de IA pode exigir uma conta ou assinatura própria.

Funciona no WoW Retail ou em outras versões?+

O suporte documentado é para World of Warcraft: Forever (interface 16001). A compatibilidade com Retail ou outros clientes Classic não está estabelecida.

Preciso manter algum programa aberto?+

Sim. O bridge local precisa estar em execução para conversar com a IA. Os catálogos de itens e missões funcionam localmente sem o bridge.

O addon envia dados do personagem automaticamente?+

Você controla as categorias de contexto compartilhadas nas configurações e pode desativar o envio automático. Mensagens e anexos enviados manualmente ainda fazem parte da conversa.

Como recebo atualizações?+

As versões publicadas aparecerão na seção de downloads. Para instalação pelo repositório, consulte o guia de atualização: atualize o código, execute novamente o setup e reinicie o bridge.
